# Loan Eligibility & Expense Tracker

## Overview

Loan Eligibility & Expense Tracker is a simple Python console application that allows users to:

* Create an account
* Log in with their credentials
* Check loan eligibility based on age and monthly income
* Track expenses against a budget
* Receive alerts when spending exceeds the budget

This project demonstrates the use of Python fundamentals such as variables, user input, conditional statements, loops, and basic authentication logic.

---

## Features
## Age verification
user verify Age

### Account Creation

Users can create a username and password before accessing the application.

### User Login

Users must log in using the credentials they created.

### Loan Eligibility Checker

The application determines whether a user qualifies for a loan based on:

* Minimum age requirement: 21 years
* Minimum monthly income requirement: ₦50,000

### Expense Tracker

Users can enter their budget and expenses.
The application will:

* Notify users if they are within budget
* Alert users when they exceed their budget
